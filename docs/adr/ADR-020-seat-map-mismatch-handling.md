# ADR-020: 좌석 맵과 실제가 달랐을 때 알리는 방법 (Q5)

> 2026-11-22 새로 만듦: ADR-019(좌석 맵 조회)에서 불일치의 결과 관리를 나눠 이 번호에 넣고, 기존 ADR-020~021을 021~022로 옮겼다(11차 번호 이동).

- 상태: 가설 (Hypothesis) — 미측정
- 대응 질문: Q5 "화면엔 빈자리였는데 요청하니 이미 팔렸다면?"
- 선행: ADR-019(좌석 맵 조회 방식과 화면 나이)

## 문제

좌석 맵은 아무리 빨리 갱신해도 실제 상태보다 늦다(ADR-019 가설). 그래서 맵에서 빈자리로 보고 고른 좌석의 선점이 "이미 팔림"으로 실패하는 일은 남는다. ADR-019가 그 늦음을 얼마나 줄일지를 다룬다면, 이 문서는 늦음이 남았을 때 사용자가 그 사실을 빨리, 분명하게 알게 하는 방법을 다룬다.

## 가설

실패를 없앨 수 없다면, 실패한 뒤 사용자가 다시 고르기까지 걸리는 시간과 헛걸음을 줄일 수 있다. 맵이 얼마나 오래됐는지 화면이 알고, 실패 응답이 다시 조회하지 않아도 화면을 고칠 정보를 주면 헛선점이 연달아 일어나는 일이 줄어든다.

## 선택지 후보

ADR-019 인터뷰에서 나온 세 가지다(2026-11-22).

| 후보 | 내용 |
|---|---|
| 응답에 스냅숏 시각 | 좌석 맵 응답에 어느 시각 기준의 맵인지(시각 또는 버전)를 실어, 화면이 맵의 나이를 안다 |
| 실패 응답에 최신 상태 | 선점이 "이미 팔림"으로 실패하면 그 좌석들의 지금 상태를 함께 돌려줘, 다시 조회하지 않고 화면을 고친다 |
| 구역 단위 조회 | 회차 전체 1만 석 대신 구역별로 조회해 응답 크기와 캐시 단위를 줄인다 |

측정 지표와 방식은 ADR-019의 결정 뒤에 정한다.
